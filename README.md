# Yazid Hamdi's Personal Blog

This is the personal website and blog of Yazid Hamdi.

## Development

Built with [Jekyll](https://jekyllrb.com/) and powered by [Beautiful Jekyll](https://beautifuljekyll.com/).

### Prerequisites

To run this site locally, you'll need [Ruby](https://www.ruby-lang.org/) and [Bundler](https://bundler.io/).

1.  **Install dependencies:**
    ```bash
    bundle install
    ```

2.  **Start the local development server:**
    ```bash
    ./serve.sh
    ```
    Alternatively:
    ```bash
    bundle exec jekyll serve
    ```

### Customization

This site uses the **Beautiful Jekyll** theme. For a full list of customization options and supported parameters, please refer to the [official theme documentation](https://github.com/daattali/beautiful-jekyll#readme).
